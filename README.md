# Subscribe to RSS Feeds

You can subscribe to the site's RSS feeds to automatically receive updates whenever new research or articles are published.

RSS allows your phone, computer, or feed reader to automatically pull new content without needing to check the website manually.

## Setup O

1. Install an RSS reader such as:

- NetNewsWire  
- Reeder  
- Feedly  

2. Open the RSS reader app.

3. Tap **Add Feed**.

4. Paste the feed URL from this repository. Example:
bash'''
https://szizzo522.github.io/feeds/all.xml
'''
The feed will automatically update when new posts are published.
